# SafariStay Kenya — Frontend Prototype

A responsive React + Vite hotel-booking UI prototype created as a portfolio demonstration.

## Included
- Premium Kenya-focused landing page
- Destination cards and fictional hotel inventory
- Search and local frontend filtering
- Hotel detail pages
- Booking summary and checkout UI
- M-PESA / card payment interface cues (no live payment connection)
- About, contact and sign-in screens
- Responsive desktop, tablet and mobile layouts

## Not included yet
- Backend/API
- Database
- Real hotel inventory or availability
- Authentication
- Email/OTP workflows
- Live M-PESA or card payments
- Admin dashboard

## Run locally

npm install
npm run dev

## Production build

npm run build

All hotel names and inventory in this prototype are fictional and intended for UI demonstration only.
