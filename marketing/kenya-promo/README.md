# Kenyan promo — Barack Silas Mungai, website development (Remotion)

A 45-second vertical (1080×1920, 30 fps) TikTok / WhatsApp promo, built as an editable
[Remotion](https://www.remotion.dev) project. The full plan, shot list, AI-generation prompts and QA
checklist are in [STORYBOARD.md](STORYBOARD.md).

## What is real and what is a slot

- **Real and finished**: screen recordings of the working ZawadiMart site (`public/recordings/`,
  made by `tools/record-screens.cjs`), the services scene, the WhatsApp ending, subtitles in
  Sheng/Kiswahili with English lines, the dramatization label and original background music.
- **Slots to fill**: seven live-action shots of actors (`public/footage/s1-a.mp4` …) and the
  scene 4 voice-over (`public/audio/vo-scene4.wav`). Until a file exists, the video shows a
  labelled placeholder card describing the shot. These need a photorealistic video generator with
  lip-synced Kenyan dialogue, or a real shoot with actors, and Kenyan voice talent.

## Commands

```bash
npm install
npm run studio            # preview and edit in the browser
npm run render            # -> out/Barack_Silas_Mungai_Web_Development_Promo.mp4
npm run music             # regenerate the background music
npm run record            # re-record the screen footage (needs the ZawadiMart site running on :4301)
```

If Remotion cannot download its browser, point it at an installed Chrome or Chrome Headless Shell:
`REMOTION_BROWSER_EXECUTABLE=/path/to/chrome npm run render`.

## Edit

Everything said or shown is in `src/script.ts`: contact details, dialogue and subtitle timings,
shot slots, screen-recording inserts, services and the WhatsApp message. Layout and motion are in
`src/Promo.tsx`, styles in `src/styles.css`.

## Rules this project keeps

- Scenes 1–3 are a dramatization with actors, labelled on screen; they are not customer reviews.
- Only features that work in a real project are shown as footage (ZawadiMart). Other services are
  listed, not demonstrated. The checkout insert is labelled “Demo checkout”.
- The WhatsApp chat is drawn in HTML; no real conversation is used. The WhatsApp mark is the
  official glyph from Simple Icons (CC0), used unaltered to point to WhatsApp.
- Music is original (generated by `tools/music.py`), so there is no licence to clear.
